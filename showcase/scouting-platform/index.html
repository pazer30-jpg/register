Technical blueprint

Modular architecture for scalable ingestion and scouting workflows

PostgreSQL + scheduled jobs

Public-source ingestion

Adapters for federation stats feeds, league sites, club sites, news APIs, and video platforms. Each source is mapped into a canonical player schema and assigned source-quality confidence.

Normalization + deduplication

Entity resolution merges duplicate player identities across competitions using name variants, birth year, club, position, and fuzzy matching before data is written into PostgreSQL.

Search + ranking

Hybrid index combines structured filters with semantic embeddings so scouts can type “ball-winning six with progressive passing” and retrieve ranked candidates.

AI scouting intelligence

LLM-generated summaries explain why the player matters, highlight strengths and risk flags, compare stylistic peers, and recommend monitor, short-list, or reject.

Workflow tools

Watchlists, recruitment pipeline stages, internal notes, alert subscriptions, and source-management admin tools keep collaboration organized across scouts and analysts.

Operational cadence

Scheduled ingestion jobs refresh stats nightly, news hourly, and alert logic continuously. Admin controls track source health, sync latency, and parser errors.
